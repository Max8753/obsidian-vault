## Definition
-DE:
Bytecode ist ein plattformunabhängiger Zwischencode, der vom Java-Compiler aus .java-Dateien erzeugt wird. Dieser Code wird nicht direkt vom Betriebssystem, sondern von der JVM ausgeführt.

EN:
Bytecode is a platform-independent intermediate code generated by the Java compiler from .java files. This code is not executed by the operating system directly, but by the JVM.

## Why it matters
-DE:
- Plattformunabhängigkeit (Write once, run anywhere)
- Sicherheit
- Optimierung durch JIT-Compiler
- Portabel

EN:
- Platform independence (Write once, run anywhere)
- Security
- Optimization via JIT compiler
- Portable

## Example

JDK → Compiler → Bytecode → JVM → OS
        javac       .class
