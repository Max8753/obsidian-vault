**JRE – Java Runtime Environment**
# Was ist JRE?
DE:
Die JRE (Java Runtime Environment) ist die Laufzeitumgebung für Java-Programme. Sie enthält alles, was benötigt wird, um ein Java-Programm auszuführen, aber keine Entwicklungswerkzeuge.
EN:
The JRE (Java Runtime Environment) is the runtime environment for Java programs. It contains everything needed to run a Java program, but no development tools.
